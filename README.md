# Website Shop Giấy (Shoe Store Website) 👟

> A fully-featured e-commerce web application dedicated to buying and selling shoes, built to provide a seamless online shopping experience.

---

## 🚀 Features

- **Product Catalog:** Browse a wide collection of shoes categorized by brand, style, size, and price.
- **Product Details:** View high-resolution images, descriptions, available sizes, and customer reviews.
- **Shopping Cart & Checkout:** Add items to the cart, update quantities, and proceed through a streamlined checkout flow.
- **User Authentication:** Secure user registration, login, and profile management.
- **Admin Dashboard (if applicable):** Manage products, categories, orders, and customer accounts.
- **Responsive Design:** Optimized layout for seamless shopping on mobile devices, tablets, and desktops.

## ⚙️ Installation & Setup

Follow these steps to run the project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/huyphanquoc1208/Website-ShopGiay.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Website-ShopGiay
   ```

3. **Install dependencies:**
   *(If using Node.js)*
   ```bash
   npm install
   ```

4. **Configure the Database:**
   - Import the provided database schema file into your database management tool (e.g., phpMyAdmin, MySQL Workbench).
   - Update your database connection credentials in the configuration file.

5. **Run the application:**
   - For static websites, open `index.html` via Live Server in your editor.
   - For backend-driven applications:
     ```bash
     npm start
     # or
     php -S localhost:8000
     ```
