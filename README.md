## 👟 Website Shop Giày (E-Commerce Shoe Store)
Dự án website thương mại điện tử chuyên kinh doanh giày dép, cung cấp trải nghiệm mua sắm trực tuyến mượt mà cho khách hàng và trang quản trị tiện lợi cho chủ cửa hàng.

### 🚀 Tính năng nổi bật
* **Phía Khách hàng (Client):**
  * Đăng ký, đăng nhập tài khoản và quản lý thông tin cá nhân.
  * Tìm kiếm, lọc sản phẩm theo thương hiệu, kích cỡ, mức giá.
  * Xem chi tiết sản phẩm, hình ảnh và đánh giá từ người dùng.
  * Thêm sản phẩm vào giỏ hàng và tiến hành đặt hàng trực tuyến.
  * Theo dõi trạng thái đơn hàng đã mua.
* **Phía Quản trị (Admin):**
  * Quản lý danh mục sản phẩm và kho hàng (Thêm, sửa, xóa, cập nhật số lượng).
  * Quản lý đơn hàng và trạng thái thanh toán của khách hàng.
  * Thống kê doanh thu, báo cáo số lượng sản phẩm bán ra theo ngày/tháng.

### 🛠️ Công nghệ sử dụng
* **Frontend:** HTML5, CSS3, JavaScript / Bootstrap
* **Backend:**  Java

### ⚙️ Hướng dẫn cài đặt
1. Clone repository về máy:
   ```bash
   git clone https://github.com/huyphanquoc1208/Website-ShopGiay.git
   ```
2. Cài đặt các gói thư viện phụ thuộc (tùy theo môi trường dự án):
   ```bash
   npm install
   ```
3. Cấu hình cơ sở dữ liệu và chạy ứng dụng.
